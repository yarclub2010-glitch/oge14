# Тренажёр задания 14 ОГЭ

Веб-тренажёр задания 14 ОГЭ по информатике: обработка большого массива данных
в электронной таблице. Работает в браузере, установка не нужна.

**Открыть:** https://yarclub2010-glitch.github.io/oge14/

Тренажёр задания 13 (презентация или текстовый документ): https://yarclub2010-glitch.github.io/oge13/

Тренажёр задания 15 (исполнитель Робот): https://yarclub2010-glitch.github.io/oge15/

Тренажёр задания 16 (программа на Python): https://yarclub2010-glitch.github.io/oge16/

## Возможности

- **Задание с файлом — как на экзамене.** Условие в формате ОГЭ, файл `.ods` с большой
  таблицей (до 1000 строк) для скачивания. Ученик решает у себя в LibreOffice Calc, МойОфис, Р7-Офис
  или Excel, сохраняет файл и загружает его на проверку.
- **Проверка по критериям ФИПИ:** три оцениваемых элемента (два числовых ответа и
  круговая диаграмма), 0–3 балла. Ответ в другой ячейке засчитывается, как в критериях.
  У диаграммы проверяются тип, данные, легенда и подписи значений.
- **Пояснение ошибок:** «>» вместо «>=», учтено одно условие из двух, слишком сильное
  округление, лишние сектора, проценты вместо значений, нет легенды и т. п. Видна формула
  ученика в привычной записи.
- **Шесть сюжетов из открытого банка:** олимпиада (как в демоверсии 2026–2027),
  тестирование по округам, грузоперевозки, погода, интернет-магазин, медосмотр.
  У каждого — тысячи вариантов с разными данными и числами в вопросах.
- **Практикум:** тестовая таблица на 30 строк прямо в браузере и типовые вопросы —
  от простого СЧЁТЕСЛИ до процентов, среднего по двум условиям и диаграммы. Формулы
  пишутся как в Calc (русские и английские имена функций), есть протягивание вниз.
- Подсказки, решения, справка по функциям и построению диаграммы, тёмная тема,
  телефон и планшет. Файл ученика проверяется прямо в браузере и никуда не отправляется.

Ссылку на вариант можно отправить ученикам — у всех будет одна и та же таблица:
https://yarclub2010-glitch.github.io/oge14/#olymp/1 (задание / номер варианта).
Практикум: https://yarclub2010-glitch.github.io/oge14/#practice

## Структура проекта

```
index.html            — страница тренажёра
src/
  main.js             — связывает всё вместе: режимы, скачивание, проверка, практикум
  tasks.js            — задания: генераторы данных, вопросы, ответы, типичные ошибки, решения
  checker.js          — проверка присланной таблицы по критериям, пояснения
  workbook.js         — создание .ods и чтение .ods/.xlsx: ячейки и диаграммы
  zip.js, xml.js      — архивы и разбор XML внутри файлов таблиц
  practice.js         — практикум: тестовые таблицы и типовые вопросы
  formula.js          — формулы: разбор и вычисление (СЧЁТЕСЛИ, СРЗНАЧЕСЛИ, ЕСЛИ…)
  sheet.js            — таблица практикума
  pie.js              — круговая диаграмма (SVG)
  style.css           — оформление
tests/                — автотесты (открыть tests/index.html через локальный сервер)
tests/fixtures/       — решения, сохранённые настоящим LibreOffice Calc: верные и с ошибками
```

## Как добавить задание

В `src/tasks.js` добавьте объект `task({...})` в массив `TASKS`: `id`, `level`, `title`,
`intro`, столбцы `columns`, генератор `generate(variant)` (данные и параметры вопросов),
тексты вопросов `questions(params)`, функцию `evaluate(rows, params)` с верными ответами,
данными диаграммы и типичными ошибками, подсказку `hint` и решение `solution`.
Автотесты проверят, что формулы решения на полной таблице дают эталонные ответы.

Если изменить генератор данных существующего задания, файлы в `tests/fixtures`
(вариант 1) перестанут совпадать с таблицей — их нужно пересоздать в Calc.

## Запуск на компьютере для разработки

Дважды щёлкните `start-server.bat` (нужен Python) — откроется http://localhost:8000.
Отправить изменения на GitHub — `sync.bat`.
